# Visual assets

Place final artwork here using the **approved asset IDs** from `lib/assets.ts`.

Example: for `ash_home_hero_v01`, add a file such as:
- `ash_home_hero_v01.png`, or
- `ash_home_hero_v01.webp`

Then set `path: "/assets/ash_home_hero_v01.png"` (or your filename) in the registry in `lib/assets.ts` for that asset. The homepage will then show the image instead of the placeholder.

Until paths are set, the site shows stable placeholder containers with the asset ID label.
